=========================
CLI版
=========================

コマンドラインで動く版です。Android版とは別にデータを持ちます。

動作環境
========

- Linux(Ubuntu 24.04 で確認)
- Python 3.9 以上(3.9〜3.14 でテストが通ることを確認。3.8 以前は動きません)
- 標準ライブラリだけで動きます。追加のパッケージは不要です

起動方法
========

.. code-block:: console

   $ git clone <リポジトリの URL> eyedrop
   $ cd eyedrop
   $ drugdb/cmd_drugdb.sh help

データベースは、既定ではプロジェクト直下の ``eyedrop.db`` です(無ければ新しく作ります)。
別の場所を使う場合は ``-f`` オプションか環境変数 ``EYEDROP_DB`` で指定します。
指定したファイルが無いとエラーになります(打ち間違いで空のデータベースを見てしまわないため)。
新しく作るときは ``--create`` を付けます。

.. code-block:: console

   $ drugdb/cmd_drugdb.sh -f ~/eyedrop.db drugs
   $ drugdb/cmd_drugdb.sh -f ~/new.db --create add 目薬A
   $ export EYEDROP_DB=~/eyedrop.db

``python3 -m drugdb`` でも起動できます(プロジェクト直下で実行)。

使用例
======

以下の例は、説明用の架空のデータ(目薬A・B・C)です。

日付は ``-d 2026-07-10``\ ・\ ``-d 2026/7/10``\ ・\ ``-d 7/10``\ (今年)で指定できます。省略すると今日です。

目薬を登録する
--------------

.. code-block:: console

   $ drugdb/cmd_drugdb.sh add 目薬A
   登録しました: 1 目薬A
   $ drugdb/cmd_drugdb.sh add 目薬B --max-days 28     # 開封後4週間で廃棄(廃棄期限)
   登録しました: 2 目薬B
   $ drugdb/cmd_drugdb.sh add 目薬C --as-needed       # 随時使用
   登録しました: 3 目薬C

処方された(入庫)・開封した
------------------------------

.. code-block:: console

   $ drugdb/cmd_drugdb.sh in 目薬A 3 -d 2026-07-10    # 3本処方された
   在庫: 3
   $ drugdb/cmd_drugdb.sh open 目薬A -d 2026-07-21    # 新しい1本を開封
   在庫: 2

``open`` は、在庫から1本減らし、使っていた1本を「使い切り」にして、
新しい1本の使用を開始します。間違えた開封は ``undoopen`` で取り消せます。

一覧・履歴を見る
----------------

.. code-block:: console

   $ drugdb/cmd_drugdb.sh drugs
     1 目薬A  在庫0
     2 目薬B  在庫0  (廃棄期限28日)
     3 目薬C  在庫2  (随時使用)

   $ drugdb/cmd_drugdb.sh life 目薬A
       1 2026-05-01 〜 2026-05-27  26日
       2 2026-05-27 〜 2026-06-24  28日
       3 2026-06-24 〜 2026-07-21  27日
       4 2026-07-21 〜 2026-08-15  25日
       5 2026-08-15 〜 2026-09-11  27日
       6 2026-09-11 〜 (使用中)       20日

   $ drugdb/cmd_drugdb.sh stock 目薬A
       1 2026-05-01 入庫  3  残 3
       2 2026-05-01 出庫  1  残 2
       3 2026-05-27 出庫  1  残 1
       4 2026-06-24 出庫  1  残 0
       5 2026-07-10 入庫  3  残 3
       6 2026-07-21 出庫  1  残 2
       7 2026-08-15 出庫  1  残 1
       8 2026-09-11 出庫  1  残 0

``life`` の左端の番号はライフタイム(開封から使い切りまで)の ID、``stock`` の左端は在庫記録の ID です。
使用中の1本の日数は、実行した日までの日数です。

受診前サマリーを出す
--------------------

受診の直前に ``report`` を実行します。出力は Markdown です(``--plain`` でテキスト版、``-o ファイル`` でファイルにも出力)。

.. code-block:: console

   $ drugdb/cmd_drugdb.sh report -v 2026-09-25

出力(抜粋)はこうなります。

.. code-block:: markdown

   # 目薬 受診前サマリー

   - 来院日 2026-09-25
   - 次回来院日 2026-11-24(60日後)

   ## 次回来院までに必要な本数

   | 代表目薬名(目薬名) | 必要本数 | 足りない日数 | 在庫残日数 | 未開封 | 通常期間 | 開封分残日数 |
   |---|---:|---:|---:|---:|---:|---:|
   | 目薬A | 3 | 48 | 12 | 0 | 26 | 12 |
   | 目薬B | 3 | 50 | 10 | 0 | 31 | 10 |
   | 目薬C | 随時 |  |  | 0 |  |  |

   ## 目薬在庫

   | 代表目薬名 | 未開封個数 | 開封分開封日 | 経過日数 | 推定残日数 | 日数 |
   |---|---:|---|---:|---:|---:|
   | 目薬A | 0 | 9/11 | 14 | 12 | 27 |
   | 目薬B | 0 | 9/4 | 21 | 10 | 30 |

このほか、各項目の説明と「推定の根拠」(廃棄期限超過などの注意点があれば「注意」も)が出力されます。
計算のしかたは :doc:`estimate` を参照してください。

出力した Markdown は、そのまま Evernote Web のノートなどに貼り付けられます。
``--ai`` を付けると、チャットAI に貼り付ける指示と JSON を出力します。

来院日・次回来院日を指定する
----------------------------

``-n``\ (``--next``)で次回来院日を日付か期間で指定できます。
省略すると来院日の2ヶ月後です(``interval`` で変更できます)。

.. code-block:: console

   $ drugdb/cmd_drugdb.sh report -n 11/20       # 次回来院日を日付で
   $ drugdb/cmd_drugdb.sh report -n 4週間       # 来院日から4週間後
   $ drugdb/cmd_drugdb.sh interval 8週間        # 既定の期間を8週間に

期間は「2ヶ月」「8週間」「60日」「60」のように指定できます(1ヶ月=30日)。

``-v``\ (``--visit``)で来院日を指定すると、その日時点の在庫・開封中の1本・実績で計算します。
過去の受診日で試して、実際に処方された本数と比べるのに便利です。

.. code-block:: console

   $ drugdb/cmd_drugdb.sh report -v 2026-09-20 -n 2026-11-15

対話シェル
----------

引数なしで起動すると対話シェルになります。``help`` でコマンド一覧、``コマンド -h`` でそのコマンドのヘルプが出ます。
対話シェルでは ``visit``\ ・\ ``next`` で来院日・次回来院日を設定しておくと、以後の ``report`` はその日付で計算します。

.. code-block:: console

   $ drugdb/cmd_drugdb.sh
   目薬管理 (help でコマンド一覧、 q で終了)
   eyedrop> visit 9/25
   来院日 2026-09-25
   次回来院日 2026-11-24(60日後)(既定: 2ヶ月後)
   eyedrop> next 11/20
   来院日 2026-09-25
   次回来院日 2026-11-20(56日後)
   eyedrop> report

よく使うその他のコマンド
------------------------

.. list-table::
   :header-rows: 1

   * - コマンド
     - 内容
   * - ``inv 目薬A 2``
     - 棚卸し。未開封の在庫数を2本とする
   * - ``alias 目薬A ジェネリック名``
     - ジェネリックなどで実際にもらう目薬の名前が変わったとき
   * - ``irregular 5 -m 紛失``
     - ライフタイム(ID は ``life`` で表示)をイレギュラーにし、推定から外す
   * - ``pattern 目薬A -m 1日2回→1回``
     - 点眼パターン変更。直近の1本をイレギュラーにし、それより前の実績を推定に使わない
   * - ``finish 目薬A -i -m 中止``
     - 次を開封せずに使用中の1本を終わらせる(中止・紛失など)
   * - ``end 目薬A``
     - 目薬の使用をやめた(サマリーに出さない)
   * - ``set 目薬C as_needed yes``
     - 随時使用に変更
   * - ``rollover``
     - 年次更新。一昨年以前の記録をバックアップ・CSV に退避
